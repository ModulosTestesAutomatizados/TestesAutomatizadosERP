# Arquivo histórico da documentação

`html/` contém cópias preservadas dos cinco índices anteriores, com nomes por assunto. Esses arquivos são evidência editorial, não a aplicação atual, e não são publicados pelo build do portal.

`migracao.md` registra a correspondência entre os títulos anteriores e os módulos de conteúdo. As referências históricas apresentadas no portal ficam em `../content/historico/`, com layout compartilhado.

`../redirecionamentos/` contém as entradas de compatibilidade. O manifesto permite que o build mantenha as URLs anteriores sem conservar pastas numeradas na raiz dos fontes.
